# GHS hazard pictograms

`GHS01.svg` … `GHS09.svg` are the official UN GHS hazard pictograms, taken from
Wikimedia Commons (category [GHS pictograms](https://commons.wikimedia.org/wiki/Category:GHS_pictograms)).
Each is a plain SVG: a red diamond border, a white diamond interior as the standard
requires, and the black symbol — with a transparent canvas around the diamond.

| File | Commons source | Hazard |
| --- | --- | --- |
| `GHS01.svg` | `GHS-pictogram-explos.svg` | Explosive |
| `GHS02.svg` | `GHS-pictogram-flamme.svg` | Flammable |
| `GHS03.svg` | `GHS-pictogram-rondflam.svg` | Oxidising |
| `GHS04.svg` | `GHS-pictogram-bottle.svg` | Gas under pressure |
| `GHS05.svg` | `GHS-pictogram-acid.svg` | Corrosive |
| `GHS06.svg` | `GHS-pictogram-skull.svg` | Acute toxicity |
| `GHS07.svg` | `GHS-pictogram-exclam.svg` | Harmful / irritant |
| `GHS08.svg` | `GHS-pictogram-silhouete.svg` | Health hazard |
| `GHS09.svg` | `GHS-pictogram-pollu.svg` | Hazardous to the environment |

The pictograms are in the public domain (UN work; the Commons files are tagged
`PD-self` / `PD-shape`). The file names match the codes used in the registry graph,
so `app-ghs-pictogram` resolves `assets/ghs/<code>.svg` directly.
